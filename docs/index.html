Core Engineering Features

Built with production-grade patterns to ensure scalability and developer experience.

Precision Staggering

Dynamically staggers email delivery using BullMQ delayed jobs to prevent hitting ESP rate limits when sending bulk campaigns.

Idempotent Execution

Guarantees zero duplicate emails even if the worker process crashes mid-execution, utilizing Postgres transactions and Redis locks.

Elastic Search

Full-text search capabilities across millions of scheduled and sent emails powered by a dedicated Elasticsearch cluster.

Slack Notifications

Real-time webhook integration pushing critical rate-limit alerts directly to the user's Slack workspace.

Neon DB Pooling

Prisma is configured to handle serverless Postgres connection pooling via PgBouncer for massive parallel worker execution.

Fully Dockerized

Entire 5-tier architecture is containerized. Spin up the entire cluster locally with a single make run command.
